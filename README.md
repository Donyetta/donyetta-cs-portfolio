# donyetta-cs-portfolio

Welcome to my personal portfolio page!
This project shows my work as a Software Development & Coding student at ECPI University. It includes an introduction, a generated
projects section, a skills list, a contact form, and interactive features such as a dark mode and a session based welcome modal.

This portfolio was built as part of an assignment from my JavaScript class.

Languages Used:
HTML - For Structure and layout
CSS3 – Styling, layout, dark mode, modal design
JavaScript
DOM manipulation
Event handling
Dynamic rendering
Web Storage (localStorage + sessionStorage)

This project runs directly in the browser, just open the index.html file in any web browser. 
my goal is to continue updating my portfolio page with what I have learned throughout my time here at ECPI.
